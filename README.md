This is my personal packaging of [VeroRoute](https://sourceforge.net/projects/veroroute/) as a [Flatpak](https://flatpak.org/) so that it's easier to use on Linux distributions that prefer Flatpaks.

To use:

1. Download and extract from https://nightly.link/carlgreen/veroroute-flatpak/workflows/build/main/veroroute-x86_64.flatpak.
2. Run something like `flatpak install --user ~/Downloads/veroroute-x86_64.flatpak/veroroute.flatpak`.
